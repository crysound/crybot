# Cry Bot brand assets

- `B.svg` — full logo (use above 32 px). `B-16.svg` — simplified logo for 32 px and below.
- `icon-macos.png` (1024, transparent corners), `icon-512.png`, `icon-maskable-512.png` (opaque, safe zone), `icon-windows.ico` (16–256), `tray-windows.ico`.
- `gen.mjs` — reference generator for the gradient, outline and face geometry (colors and shapes are defined there).

These files are the single source for every app icon and the mascot look. Do not use any other logo.
