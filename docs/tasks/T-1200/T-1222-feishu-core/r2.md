2. **`server/feishu-login.test.ts` 补齐 brief 列出的分支**，每条断言具体值：token 接口非 2xx、坏 JSON、没有 access_token；超时；租户不对；`feishuScopes` 四个分支（含「无 ADMINS 且 ALLOW=`*`」）；ALLOW 里的邮箱被忽略并警告；拒绝日志含 union_id、不含 code 和 Secret；配了 APP_ID 没配 TENANTS 返回 null；`_FILE` 优先于直接值；HOSTED_WORKSPACE、CLOUD_TEAM 时返回 null。
3. **飞书不可用被当成 code 无效（`server/feishu-login.ts:112-115`、`server/feishu-routes.ts:188-189`）。** 现在超时、网络错误、5xx 都归成 `feishu_token_failed`，路由映射成 `400 feishu_code_invalid`。规格 3.4 要求飞书不可用时 `502 feishu_unavailable`。改成两类：请求异常、超时、5xx → unavailable（502）；4xx 或响应里没有 access_token → code_invalid（400）。user_info 同理。
4. **没配飞书时先查 Origin（`server/feishu-routes.ts:170-171`）。** 没配飞书时带 Origin 返回了 403，应该是 404，且不能暴露路由存在。把 `!options.config` 判断挪到最前面。并且没配飞书时 `/api/auth/feishu/` 下**所有**路径和方法（不只 `POST exchange`）都返回 404（验收第 2 条）；补测试。
