   - 夹默认资源的函数改成需要调用方显式传入宿主（容器引擎）资源 `{ cpus, memoryGb }`；**调用方不传时直接用 DEFAULT_DESKTOP_RESOURCES（4G/2 核），不要回退到 os.cpus()/totalmem()**。这样本批合并后线上现有调用方（server/routes/computers.ts:328、server/index.ts:5633、:11669）行为不变，等后续接线任务再传引擎实际资源（docker info 的 NCPU/MemTotal）。
   - 传入宿主资源时：内存先 Math.floor 成整数，再保底到 MIN_DESKTOP_MEMORY_GB；核数至少 1、为整数；宿主太小（夹完低于下限）就退回 DEFAULT_DESKTOP_RESOURCES 与宿主上限二者的较小合法值；任何输入（0、NaN、负数、小数）都不抛异常。
