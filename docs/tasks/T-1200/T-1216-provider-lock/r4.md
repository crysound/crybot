2. **锁定后已有端点要能编辑地址和钥匙**。服务端（`server/routes/instances.ts` 约 157、230 行）锁定时放行对已存在 Claude 端点的 `PATCH`（地址、钥匙、模型等编辑字段），DELETE 和已有端点时的第二次 POST 仍 403。前端（`ClaudeEndpoints.tsx`、`EnginesSettings.tsx`）锁定时保留端点行的「编辑」，只去掉删除和新增。补测试：锁定时 PATCH 已有端点成功，DELETE 和第二次 POST 返回 403。
