# T-1209 第 3 轮返工(只改下面几条)

原任务见同目录 brief.md，上轮返工见 r2.md。r2 的 20 条大部分已改对(复审核过)，现在 GitHub Actions 上 iOS 和安卓都编译失败，这一轮只修下面的问题，其余不要动。

## 必改
1. **iOS xcodegen 解析失败**：CI 报 `Parsing project spec failed: Decoding failed at "path": Nothing found`。XcodeGen 的 `info` 里 `path` 是必填。`mobile/ios/project.yml` 改为 `info: { path: CryBot/Info.plist, properties: {...现有键...} }`，由 XcodeGen 生成该文件(会合并默认标准键)；删掉显式的 `INFOPLIST_FILE` 设置(设了 path 后 XcodeGen 自动配)；在 `mobile/ios/.gitignore` 里忽略 `CryBot/Info.plist`(生成物不进仓库)。README 里说明 Info.plist 由 xcodegen 生成。
2. **安卓编译失败**：CI 报 `MainActivity.kt:130:42 'val' cannot be reassigned` 和 `Assignment type mismatch: actual type is 'kotlin.String', but 'android.widget.TextView' was expected`(:135 同样)。原因：`showError` 里局部变量 `val text = TextView(...)` 遮住了后面 `Button(this).apply { text = ... }` 的 `text` 属性。把局部变量改名(如 `label`)并同步所有引用。**全文件检查**其他 `apply { text = ... }` 是否也被同名局部变量遮住(上一轮服务器地址表单处也出过同样错误)。
3. **UA 标记统一**：两端都在系统默认 UA 后追加同一格式：iOS `applicationNameForUserAgent = "Mobile/15E148 CryBotApp/<version> iOS"`，安卓保持 `<默认UA> CryBotApp/<version> Android`。
4. **安卓 15+ 系统栏对比度**：强制 edge-to-edge 后系统栏透明，insets padding 露出根容器白底，而状态栏图标是白色，看不见。根容器背景设为 `#170057`(品牌深紫)，WebView、服务器地址表单页、错误页各自设白底；保持 `windowLightStatusBar=false`(深底白字)。

## 一并改
5. iOS `en.lproj` / `zh-Hans.lproj` 的 `SERVER_ADDRESS_INVALID` 文案改成只接受 https(和代码一致)。
6. 安卓下载：「已开始下载」提示只在 enqueue 成功后显示；失败只提示「无法开始下载」；API 26–28 等存储权限时不提示「已开始」。
7. 安卓文件选择遇到 ActivityNotFound：调完 `onReceiveValue(null)` 后返回 true。
8. 安卓构建时注入的服务器地址先用 `validServer(...)` 校验，无效时当作没注入(允许用户输入并显示「更换服务器」)，和 iOS 一致。
9. `icon_background.xml` 渐变方向改为 startX=23.6 startY=0 endX=84.4 endY=108(对应 B.svg 的 (14,0)→(50,64))。
