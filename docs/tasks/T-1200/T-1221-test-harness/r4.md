```
mobile/ios/CryBotTests/Support/ServerTextRendererTests.swift:3:18: error: Unable to resolve module dependency: 'CryBot'
** TEST BUILD FAILED **
SwiftDriver CryBotTests normal arm64 ... (in target 'CryBotTests' from project 'CryBot')
```

原因：`mobile/ios/project.yml:76` 主 App 的 `PRODUCT_NAME: Cry Bot` 带空格，Xcode 推出的模块名是 `Cry_Bot`，于是 `@testable import CryBot` 找不到模块。并行进行的 App 骨架任务也有 6 个测试文件写 `@testable import CryBot`，所以要在工程配置里定死模块名，而不是改测试。

2. 截图导出的失败信息：这次因为编译失败没有产出截图，导出步骤只报「0 PNG」。导出脚本发现没有 `.xcresult` 或测试没有运行时，先打印「测试未运行（编译或启动失败），见上一步日志」再失败，免得误导人去查截图。补自测。
