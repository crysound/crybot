# T-1254 第 5 轮：CI 上的一项源码安全测试失败

原任务见本文件夹 brief.md、r2–r4.md。工作区已有的改动全部保留，这一轮只修下面这一项。

## 失败
`src/components/published-apps/preview.security.test.ts` 第 109 行在 `electron/main.mjs` 里断言：
`setWindowOpenHandler(({ url }) => { ... return { action: "deny" }; })`

本分支把主窗口的 `setWindowOpenHandler` 挪进了 `electron/login-navigation.mjs` 第 113 行附近的 `attachLoginNavigation`，所以这条断言找不到匹配。

## 要做
1. 先核实一点：主窗口的新窗口处理是否仍然**每条路径都返回 `{ action: "deny" }`**，也就是主窗口（带 preload）永远不会直接开出子窗口。
   - 如果不是，先改代码，让它满足这一点。
2. 修改断言，不删除：
   - 断言要检查 `electron/login-navigation.mjs` 里主窗口那一个处理函数。
   - 写法上要能区分主窗口的处理函数和登录窗口 `opened.webContents.setWindowOpenHandler` 的处理函数。登录窗口不带 preload，允许 `allow`。
   - 再加一条断言：`electron/main.mjs` 调用了 `attachLoginNavigation`。
   - 测试的保护强度不能比原来弱。
3. 别的源码断言如果也依赖 `main.mjs` 里已经挪走的代码，一并按同样方式修。可以全仓搜一下读取 `electron/main.mjs` 的测试来排查。
