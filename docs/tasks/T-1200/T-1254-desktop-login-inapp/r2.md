# T-1254 第 2 轮：按第 1 轮审核修 4 项必改

原任务见本文件夹 brief.md，工作区里已有的改动全部保留，这一轮只修下面四项。

## 必改
1. **登录弹窗也要受管。** `electron/main.mjs` 约 1939 行，登录弹窗直接返回 `allow`，新窗口没有装导航守卫、没有完成回调，也没有最小尺寸。改法：登录页里再弹出的窗口，要么在当前受控的登录窗口里直接承接这次导航，要么装上和登录窗口一样的守卫、完成处理和最小尺寸。统一管理所有登录窗口。
2. **不能丢掉 POST 回调。** 约 1927 行，现在一遇到服务器地址就取消原导航，再用 `loadURL` 重新发一次 GET，POST 回调（`form_post` 或 SAML）的请求体就丢了。改法：回调让它在不带 preload 的登录窗口里照常走完；确认登录成功后，再关掉登录窗口、刷新主窗口。登录成功可以用服务器源的页面加载完成、或者检查会话接口来判断，选最小改法。补一个 POST 回调的测试。
3. **只认主框架。** 约 1925 行的 `will-redirect` 处理没有检查 `isMainFrame`。改法：子框架（iframe）的导航和重定向不能结束登录，也不能触发顶层的「未允许网址」提示。只有主框架的导航才算数。补测试。
4. **补一个真正的集成测试。** 现在的「完整跳转链」测试只是遍历字符串、调分类函数。改法：
   - 用隔离的本地假服务（多个示例主机名，可以用 Host 头或多端口来模拟），驱动真实的导航守卫和窗口状态机。如果 Electron 跑不起来，就把守卫和窗口管理抽成可以注入的模块，用假的 webContents 和事件驱动。
   - 断言：整条链 `openExternal` 调用次数为零；包含 POST 回调；子框架重定向不结束登录；最后主窗口回到服务器源，登录窗口已关闭。
   - 改正 verification.txt 里「同等覆盖」的说法。
