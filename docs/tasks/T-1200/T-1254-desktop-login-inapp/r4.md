# T-1254 第 4 轮：修第 3 轮审核的 1 项必改

原任务见本文件夹里的 brief.md、r2.md、r3.md。工作区里已有的改动全部保留。这一轮只修下面这一项，别的都不改。

## 必改
`electron/login-navigation.mjs` 第 4 行、第 102–105 行：`loginNavigationKind` 先判断 `workspaceAllowed`，而服务器源只比较 `URL.origin`。结果像 `https://user:pass@server.example.test/callback` 这种带用户名和密码的地址，因为和服务器同源，会被放行。

改法：
- 在判断服务器源和登录名单之前，先统一检查三件事：协议必须是 http 或 https，不能带用户名，不能带密码。任何一项不合格都不放行。
- 主窗口导航、登录窗口导航、`will-redirect` 和弹窗处理都走这一套检查。
- 不合格的地址按「名单外地址」处理：登录过程中，在应用内提示并记日志，日志里只写主机名；登录完成后也不能加载到应用里。

补充测试：
- 服务器源带凭据的地址分三种情况测：主窗口导航、登录窗口导航、弹窗。每种都断言没有被加载，也没有调用 `openExternal`。
- 断言日志里不出现用户名和密码。
