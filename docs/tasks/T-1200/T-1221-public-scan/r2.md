## 必改
1. **域名识别（scan.mjs:28-33, 62）**：手写 TLD 白名单两头出错。
   - 误报：`user.name`、`logger.info(`、`re.test(`、`window.app`、`import.meta.env.DEV` 都报 domain；最近 6 个已合并 PR 每个都会变红。 <!-- public-scan: allow domain -->
   - 漏报：名单外的 TLD 前面没有 `://` 就不查，`api.foo.hk`、`host: build.foo.sh`、`wiki.foo.top/page` 全放行。 <!-- public-scan: allow domain -->
   - 改法：用完整的 IANA TLD 表（离线内置成一个数据文件，注明来源和日期）。会和代码成员名、文件扩展名撞的那组 TLD（name、info、app、dev、test、local、home、live、pro、js、ts、md、json、swift、py、sh 等，自己从表里挑全）要有主机上下文才算：前面是 `://`、`@`、`host:`/`url`/`href`，或整个字符串字面量就是一个主机名，且后面不跟 `(`。测试补：`user.name`、`logger.info(x)`、`re.test(s)`、`self.name` 不报；`a.b.hk`、`"build.foo.sh"`、`https://x.foo.app/` 要报。 <!-- public-scan: allow domain -->
2. **大 diff（scan.mjs:186）**：`execFileSync` 默认 maxBuffer 1MB，diff 超过就 `ENOBUFS` exit 2。改成流式读（spawn）或把 maxBuffer 调到足够大（≥256MB）；用 pathspec `:(exclude,glob)**/pnpm-lock.yaml`、`:(exclude,glob)**/Package.resolved` 在 git 层排除要跳过的文件。
3. **带引号的文件名（scan.mjs:164-165）**：`core.quotePath` 下非 ASCII 或含特殊字符的文件头是 `+++ "b/..."`，整文件被静默跳过。调用加 `-c core.quotePath=false`，并能解析带引号、C 转义的路径；读到 `+` 行却解析不出文件时报 `unparsed` 失败（失败即拦）。
4. **`.gitattributes` 绕过二进制判断（scan.mjs:160-162, 186）**：git diff 加 `--text`，是否二进制由脚本自己判断（扩展名白名单 + 检查 NUL）；PR 新增 `binary` / `-diff` 属性时直接报一条规则（名字自定，写进 README）。
5. **豁免（scan.mjs:92-93）**：删掉 `public-scan: allow all` 和别名 `token`/`hash`，只认 README 列出的规则名；多条规则写多个注释。
6. **哈希名单分词（scan.mjs:126-129）**：域名对每一级后缀都算哈希（`a.b.c` 算 `a.b.c`、`b.c`）；标识符再按 `.`、`_`、`-` 和驼峰拆成子词，每个子词也算。测试补子域名、`<词>_bot`、`<词>-team`、`<Word>Client`、`<词>.example.com` 五种写法都要报，且输出不含原文。
7. **测试要走真实 git（scan.test.mjs:13-34）**：在临时目录 `git init`、提交、改动，用 `spawnSync(process.execPath, [scan.mjs, "--base", base])` 像 CI 一样调用；断言退出码、具体的 `file:line: rule` 输出，以及 stdout+stderr 合起来不含原文。第 2–6 条各一个回归用例。测试结束删掉临时目录（用 `t.after` 或 try/finally）。

## 一起做的建议
- 工作流（public-scan.yml）：checkout 钉到和 `ci.yml` 一样的提交 SHA（带版本注释），加 `persist-credentials: false`；加钉住 SHA 的 `actions/setup-node`，node-version 24，和 ci.yml 一致；加 `timeout-minutes: 10`。
- `cry_sess_` 规则：后面至少 20 位 `[A-Za-z0-9_-]` 才报，测试里的 `cry_sess_secret`、`cry_sess_abc`、`cry_session_cookie_name` 不报。顺手把字符类里的 `-` 移到末尾。
- 四段式版本号：前面是 `v`/`version` 或后面接 `-` 时不当 IP。
- `+++` 文件头只在 `---` 之后、第一个 `@@` 之前才认。
- 新增和改名后的文件路径也做域名和名单检查，报告只报规则名。
- `denylist.sha256` 里格式不对的行（不是 64 位十六进制也不是注释）直接报错退出（exit 2）。
