## 本轮必须修的（审核意见）
1. `server/cf-access.ts:66` 有调试输出 `console.error("cf cookie", ...)`，会把会话 token 写进日志。删掉。
2. 带 Cookie 复用会话的路径（`cf-access.ts:51-54`）调的是 `sessions.issueAccess`，它只认内存里的 `accessTokens`，服务重启后会新建孤儿会话，正在用的会话名字不更新，累计 5 个后还会撤销用户的老会话。改为：在 `SessionRegistry` 加按会话 id 更新 email / displayName 的方法（如 `refreshAccessDetails(id, details)`），复用路径调它，不新建会话。补测试：带 Cookie、模拟重启（重新构造 registry 从文件加载）后再请求，名字被更新且会话数不变。
3. `server/index.ts` 的 `multipleSessionPeople`（约 896-898 行）及使用处（reactorFor、runOwners.shared、约 12784 行）：按 `personKey` 统计全部会话，会把同一人的多设备、API token 算成多人。改为：「多人」只按不同的 `accessIdentity` 或 email 统计，排除 token、访客和无 email 的配对会话。`runOwners` 的 shared 判定恢复成 main 的写法（它只适用于 Team Cloud，见 `server/host/run-owner.ts` 头部注释）。
4. 历史消息改名（约 2839-2841 行的回调和 836-840 行的 `sessionNameForPerson`）：Team Cloud 下不得改变原逻辑。团队模式直接不改写历史 sender 名字。
5. 同一处匹配：旧消息的 `sender.id` 是当时无 email 的会话按会话 id 算的 key，会话写入 email 后 personKey 变了就对不上。匹配时同时比对按会话 id 算的 key（`personKey({ id: candidate.id })`）和当前 key。
6. `userNameFor` 非团队分支（约 871 行）：对不上会话时不得回退到 `line.sender?.name`（可能是「Safari on iPhone」这类设备标签），回退到 `profile.name` 或中性称呼。
7. `src/components/ChatView.tsx:901`、`src/components/GroupView.tsx:287`：@提及自己仍用 `config.profile.name`，改为用当前会话的 displayName（有则优先）。`index.ts` 约 11842 行对 Access(admin) 会话不起作用的 profile 改写如无用就删掉，别留死代码。
8. `server/index.ts:887` 类型错误：`userNameFor(threadId)(line)` 中 `PersonName` 不全是函数（`tsc` 报 TS2349）。按 `PersonName` 的实际类型改，例如用 `speakerOf(userNameFor(threadId), line)`。
9. `server/sessions.ts:77` 不要给 `membershipAuthority` 枚举加 `"access"`（回滚到旧版本时整个会话文件解析失败，所有会话丢失）。改在 `revalidateEmailSessions` 里用 `session.accessIdentity !== undefined` 排除 Access 会话。
10. 名字清洗：`cf-access.ts:7-11` 和 `sessions.ts` 两处同样的正则抽成一个函数；按码点截断到 64（不要截出孤立代理项），并去掉 U+2028/U+2029、U+200B-U+200D、U+FEFF。
11. 删掉前端只解析不用的 `shared` 字段（`src/lib/session.ts:68`、`index.ts` 约 12784 行），除非本轮第 3 条确实用到。
12. `src/components/ProfileSettings.tsx`：只读时不挂 `onBlur={save}`；头像首字母用 displayName。

## 补测试（行为测试，断言具体值）
- 发给 AI 的人名按发言者取；对不上会话时不用设备标签。
- index 层：历史消息（sender.name 为设备标签、sender.id 为旧会话 id key）下发时显示为新名字；Team Cloud 下不改写。
- Cookie 复用 + 重启后名字刷新、会话数不变（见第 2 条）。
- `custom.name` 与顶层 `name` 同时存在时取 `custom.name`。
- 单人（同一人多设备 / API token）不算多人；两个不同 Access 身份才算多人。
- 设置页 displayName 只读并显示「来自登录账号」。
