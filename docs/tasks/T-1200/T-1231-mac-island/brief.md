# T-1231 Cry Bot Mac 灵动岛

仓库 crybot，分支 `T-1231-mac-island`，基准 main。用户已批准方案，按下面做，不要改设计。

## 目标

macOS 桌面版在屏幕顶部刘海位置加一个「灵动岛」，四种形态：

1. **隐藏（默认）**：什么都不显示，只有刘海本身。整块区域鼠标穿透，不挡菜单栏。有智能体等确认时也不显示任何东西（只靠已有的系统通知）。
2. **简介（鼠标悬停刘海区域）**：黑色胶囊从刘海往下长出一条，左边是全部智能体的真实头像叠成一排（最多显示 6 个，多的显示 +N），右边是总状态文字，例如「6 个智能体 · 3 在干活 · 1 等你」。鼠标移开收回隐藏。
3. **列表（简介状态下点一下）**：往下展开成网格，每个智能体一格：真实头像（右下角状态小圆点）、名字、状态（在干活 / 等你确认 / 空闲 / 离线）、正在做的事（一行，超出省略）。等你确认的排在最前并用暗黄底高亮。超过 6 个可以上下滚动。鼠标移开 1 秒、按 Esc、点别处都收回隐藏。
4. **对话（列表里点某个智能体）**：岛变成对话框：返回箭头、头像、名字、状态、「在主窗口打开」；最近几条消息（实时流式更新回复）；有待确认的审批时显示允许/拒绝按钮；底部输入框「给 <名字> 发消息…」。消息发到**这个智能体最近的那条对话**（和主窗口看到的是同一条）。正在输入时鼠标移开不收起；Esc 或点别处收回隐藏；点返回回到列表；「在主窗口打开」把主窗口切到这条对话并聚焦。

视觉要点（用户已看过效果图）：纯黑胶囊，上边与屏幕顶边贴齐、下方大圆角（简介约 22px，列表/对话约 28px），带柔和阴影；简介高度约菜单栏高度 + 24px；列表每行 3 格、头像约 52px；对话框宽约 460px，消息气泡 #1c1c1e、按钮「发送」绿、「先别发」深灰；状态色：在干活绿 #7ee787、等你确认黄 #f0b429、空闲灰 #8b8b8b。

## 其他已定的决定

- **头像和名字**：必须复用 `src/components/Avatar.tsx` 里的 `BotAvatar`/`MascotAvatar`，和主窗口完全一致；不许用彩色圆点替代。
- **没有刘海的屏幕**（外接显示器、旧款 Mac）：菜单栏正中留一块看不见的感应区（宽约 200px、高为菜单栏高度），鼠标放上去照样出简介。
- **显示哪里的智能体**：始终和主窗口当前显示的地点一致（本机 / 云电脑 / 其他服务器）。主窗口切换地点后，岛上的列表、状态、对话随之切换。弄清主窗口当前地点是怎么定的（参考 `electron/account-places.mjs`、`electron/cloud-connections.mjs`、`electron/remote-only.mjs`、`electron/main.mjs`），岛与主窗口取同一个来源，不要另存一份。
- 只在 macOS 上启用；其他平台不创建窗口。设置里加一个开关「显示灵动岛」（默认开），以及「全屏应用时也显示」（默认开）。

## 技术做法（参考，以代码实际为准）

- 窗口照搬 `electron/talk-panel.mjs`：`type: "panel"`、透明、无边框、不抢焦点、`setAlwaysOnTop(true, "screen-saver")`、`setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true })`。窗口固定为最大尺寸、放在主显示器 `display.bounds` 顶部居中，展开收起只在页面里做 CSS 弹性动画；透明部分 `setIgnoreMouseEvents(true, { forward: true })`，鼠标进入胶囊区域再关掉穿透。
- 岛窗口不能出现在 `appWindows()` 之类的主窗口枚举里（不影响退出、聚焦、窗口菜单等现有逻辑）。
- 岛页面不直接请求服务。由主进程用现有的 `localServerRequest`（或主窗口当前地点对应的请求方式）获取 `GET /api/bots`、发 `POST /api/bots/:id/messages`、订阅 `/api/events`，经 preload 暴露的窄接口转发给岛页面；复用现有写入令牌校验，不新增对外端口。
- 刘海判断：用 `display.bounds` 与 `display.workArea` 的差（菜单栏高度）判断，带刘海的机型菜单栏更高；胶囊宽度在设置里可微调（默认按刘海宽度约 200px）。
- 界面用 React + `@crysound/ui`（项目里已有），深色样式；新建一个独立的小页面入口，文案中英文都要（走现有 locales）。
