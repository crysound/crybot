## 必改
1. **SSE 坏帧连累好帧（`Sources/CryCore/SSEParser.swift:20-36、59-62`）。** 同一块数据里 s:1 好、s:2 字段类型错、s:3 好，现在一个都不交出、`lastEventID` 却停在 s:2，按游标续传 s:1、s:3 永久丢。改成按帧隔离：坏帧跳过并计数（或返回值里带错误），其他帧照常交出；对齐网页 `src/lib/live-events.ts` 的 `parseLiveFrame` 只跳过坏帧。补「好、坏、好在同一块数据」的用例。
2. **`id:` 行一到就提交 `lastEventID`（`SSEParser.swift:68`）。** 改成 `id:` 先进缓冲，空行派发时才提交（HTML SSE 规范）。补「`id: s:5` + 半截 `data:` 后 `finish()`，`lastEventID` 不变」的用例。
3. **`config` 帧用合并，旧字段残留（`Sources/CryCore/LiveState.swift:104-105`）。** 服务端每次发完整配置（`server/index.ts` 里 `broadcast({ kind: "config", ...configStatus() })`），网页整体替换（`src/state/store.tsx:1039`）。改成整体替换（去掉 `kind`），并改掉 `LiveStateTests.swift:93-99` 把留旧值当预期的断言。
4. **未读数和配置没有初始值入口（`LiveState.swift:31-55`）。** 规格第 1.3 节不许功能任务改 Packages，02/23 补不上。加 `load(notifications:)`（用通知列表接口的响应类型）和 `load(config:)`（`/api/config` 的响应类型），对照网页 hydrate 的做法，补测试。
5. **上传文件名里的 `+` 变空格（`Sources/CryCore/Endpoint.swift:44、128`）。** `URLComponents.queryItems` 不编码 `+`，服务端 `url.searchParams.get("name")`（`server/routes/threads.ts:406`）会解成空格。自己设 `percentEncodedQueryItems`，编码规则对齐 `encodeURIComponent`（网页 `src/lib/composer-attachments.ts:382`），EndpointTests 补 `C++ notes&x=1.txt` 这类文件名，断言 query 里是 `%2B`。其他带 query 的端点一起走这套编码。
6. **模拟器选择（`.github/workflows/mobile.yml`「Select iPhone 16 simulator」）。** 按规格第 8 节第 343 行：优先最新 iOS 运行时里可用的 iPhone 16；没有就用 `xcrun simctl create` 在最新 iOS 运行时补建一台 iPhone 16（device type 用 `simctl list devicetypes` 查出的 identifier）；连 iPhone 16 的 device type 都没有时，退到最新运行时里任意一台可用 iPhone。选中/新建/退回哪一台都在日志里打印出来。
7. **安卓构建不能再漏触发。** `mobile.yml` 的 push 和 pull_request `paths` 现在只有 `mobile/ios/**`，以后只改 `mobile/android/**` 不触发 android job。两处 `paths` 都加回 `mobile/android/**`（ios job 本身不必因为安卓改动跳过，保持简单即可）。
8. **依赖版本对不上（`mobile/ios/project.yml` packages 段）。** 现在的 LiveKit 2.5.0 锁定的 WebRTC 版本和 `LiveKitWebRTC` 写的 125.6422.06 不一致，解析会失败；另外几个也不是最新稳定版。协调者已核对，改成：
   - `LiveKit`（client-sdk-swift）`exactVersion: 2.19.0`
   - `LiveKitWebRTC`（webrtc-xcframework）`exactVersion: 150.7871.04`
   - `SwiftMarkdown` `exactVersion: 0.9.0`
   - `SwiftMath` `exactVersion: 1.7.3`
   - `HighlightSwift` `exactVersion: 1.1.0`
   如果代码里用到了这些库在新版本里改名或删掉的 API，按新版本改；沙箱禁网不能解析，照实写明哪些没法本机验证，由 Actions 判定。报告和 `third_party` 相关说明里的版本号同步。
