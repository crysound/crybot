# T-1207 第 11 轮：CI 的 vitest 分片

基于 HEAD（第 10 轮已提交）。只改 `.github/workflows/ci.yml`。

## 背景
仓库有 300 多个 `*.e2e.test.ts`，每个都会真起一次服务器。CI 里 `pnpm vitest run --maxWorkers=2` 单个 job 跑一小时以上，拖慢每次合并。

## 要做
- 把现在的单个 `check` job 拆成两部分：
  1. `check`：保留 install、`tsc -b`、`tsc -p tsconfig.server.json`、`pnpm lint`、`pnpm i18n:check`、`pnpm check:brand`，不跑 vitest。
  2. `vitest`：`strategy.matrix.shard: [1, 2, 3, 4]`、`fail-fast: false`，每片跑 `pnpm vitest run --maxWorkers=2 --shard=${{ matrix.shard }}/4`。步骤里的 checkout / pnpm / setup-node 保持现在锁定的同一组完整 SHA 和 node 24、pnpm 缓存不变，install 同样 `--frozen-lockfile`。
- 两个 job 都加 `timeout-minutes: 45`。
- 不改 `on:`、`permissions:`，不新增第三方 action。
- 确认 YAML 有效（例如 `node -e` 用仓库已有依赖解析，或 `python3 -c 'import yaml'` 若可用）。

报告追加到 report.md「第 11 轮」。不要 git 提交。
