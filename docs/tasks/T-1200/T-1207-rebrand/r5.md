## 背景(协调者已核实)
- 打包版的托管服务地址默认已经是空串(`electron/account-service.mjs:20`)，托管功能没有可连的端点。所以本轮目标是：
  - 用户看不到、也点不到任何托管云入口；
  - 进程启动时不初始化托管客户端；
  - 去掉能把程序指向托管服务的环境变量；
  - 删除只服务于托管的「叶子」模块；
  - 全部测试回绿。
- 有一批模块和本机或自填服务器共用，牵连很深，**本轮不删**，协调者会另开台账任务处理：cloud-sync-*、one-home*、own-home-main、home-window*、team-*、organization-*、org-library、cloud-send*、cloud-list、cloud-power、cloud-connections、cloud-logins、cloud-signin、cloud-space、rail-accounts、lending 等。本轮只保证：没有托管账户时，它们不被调用、不外连、不出现在界面上。

   - `src/components/cloud-buy/` 整个目录；`src/components/CloudAddDialog.tsx` 及其测试；`src/lib/cloud-plan.ts` 及其测试；`src/lib/cloud-extra.ts`、`src/lib/cloud-look.ts` 中只服务于购买或套餐的部分。

   - `electron/account.mjs`(上游云账户、OTP、付费)及其 IPC。
   - `src/locales/*.json` 里只被上述 UI 使用的键，以及 `src/locales/source-hashes.json` 里对应的条目。如果 package.json 里有生成 hashes 的脚本，就用它重新生成，不要手工改 1500 行。

2. **去掉托管服务地址开关**：
   - 删除 `electron/account-service.mjs:86-89` 对 `CRYBOT_CONTROL_PLANE_URL` 的读取，`controlPlaneURL` 恒为空。
   - 地址为空时，相关函数直接返回「未启用」，不发任何请求。
   - 删除 `DEFAULT_COMPANION_CONTROL_PLANE_URL`。
   - `electron/companion-e2e-desktop.mjs:10` 的注释同步修改。
