## 必改：中继主机校验能被 IP 简写绕过

位置：`shared/pairing-link.ts:23-24`、`electron/relay-token.mjs:10-11`、`companion/src/e2e/descriptor.ts:11-12`。

现在 `IPV4_STYLE = /^(?:\d{1,3}\.){3}\d{1,3}$/` 只挡标准四段十进制。下面这些都被放行，而 `new URL`/DNS 会把它们解析成本机或内网地址：
`127.1`、`0x7f.0.0.1`、`0177.0.0.1`、`0x7f.1`、`10.1`、`192.168.1`、`00127.0.0.1`；另外 `foo.localhost` 也放行（解析到 ::1）。companion 用 `wss://${node}` 拨号，所以是真能连过去的。

改法（三处一致）：
- 最后一段是纯数字或 `0x` 开头的十六进制（`/^(?:\d+|0x[0-9a-f]*)$/i`）就拒绝，这与 WHATWG URL「以数字结尾即按 IPv4 解析」的规则一致；正常顶级域名不会是纯数字，不误伤。
- 拒绝 `localhost` 以及所有以 `.localhost` 结尾的主机名（大小写不敏感，含结尾带点 `localhost.` 的写法——结尾带点本来就不该通过）。
- 三处测试都补：`127.1`、`0x7f.0.0.1`、`0177.0.0.1`、`0x7f.1`、`10.1`、`192.168.1`、`00127.0.0.1`、`foo.localhost`、`LOCALHOST`、`relay.localhost` 拒绝；`relay.example.com`、`r1.relay.example.com` 通过。
- 三份实现要保持一致：electron 和 companion 打包后不能跨目录引用 shared（第 9 轮报告已说明），所以保留三份，但加一个测试（放在 shared 或 electron 的现有测试里都行）用同一组样例分别调三份实现，结果必须完全一致，防止以后只改一处。
