# Cry Bot execution spec (2026-11-13)

Cry Bot is a fork of OpenMausBot v0.1.155 (Apache-2.0, commit 8b17baf). It is rebranded completely and self-hosted. This spec is the contract for every task in this effort. Reviewers check work against it.

## 1. Goals

1. No trace of the upstream brand anywhere a user, an operator or a client can see: UI text in every locale, window titles, app names, icons, mascot art, CLI command, env vars, data directories, cookies, headers, URL schemes, bundle ids, docker labels, systemd unit names, file formats, logs.
2. The product never contacts upstream services (telemetry, updates, accounts, cloud, relays, announcements, catalogs, promos).
3. Login is done by Cloudflare Access in front of the server. The server trusts a verified Access JWT.
4. Clients: web (PWA), Windows and macOS desktop (Electron), Android and iOS (thin native WebView shells).

## 3. Licensing

- Keep `LICENSE` (Apache-2.0) unchanged.
- Keep `NOTICE`. Prepend: `Cry Bot\nCopyright 2026 Hangzhou Crysound Electronics Co., Ltd.\n\nThis product includes software developed by the OpenMausBot project (https://github.com/milind-soni/OpenMausBot), licensed under the Apache License 2.0, and has been modified.` Keep the rest verbatim.
- Add `CHANGES.md`: a short statement that files were modified from OpenMausBot v0.1.155 (rename, removal of enterprise and hosted services, Cloudflare Access login, new clients). This satisfies Apache-2.0 §4(b).
- Delete `enterprise/` and every reference to it. The edition is always open source. Remove whitelabel/brand.json loading that depends on enterprise.
- Rewrite `LICENSING.md` for Cry Bot (Apache-2.0, third-party notices in `third_party/`, no trademark section about upstream marks).
- Third-party license files and attribution headers stay as they are. Packaged apps keep shipping them (electron-builder `extraResources` licenses).
- The upstream name may appear only in `NOTICE`, `CHANGES.md`, `LICENSING.md` attribution lines and `third_party/` content. The residual check (§8) whitelists exactly these.

## 4. Brand and mascot

- Source assets: `brand/` (logo `B.svg`, small logo `B-16.svg`, rendered icons, reference generator `gen.mjs`). The look: rounded square with a purple gradient (`#5b3fe0`→`#170057` family, see `gen.mjs`) and a white dome face with two eyes.
- Replace every app icon: `build/icon*.{png,svg,icns,ico}`, `build/icon.iconset`, `public/app-icon*`, `public/apple-touch-icon.png`, PWA manifest icons, favicon, tray icons, DMG background art if it shows the old mascot or name.
- Mascot: the default mascot body becomes the dome shape from the logo (white dome, eyes in the existing face system). Remove the cursor/mouse body and anything that draws a mouse or a cursor-shaped mascot. Keep the face/expression system and the other neutral bodies (blob, circle, squircle, capsule, drop, shield, hexagon, diamond, star). Stored bot settings with an unknown or removed body id fall back to the default body (this fallback exists already).
- Mascot names list (`src/lib/mascot-names.ts`) must not contain upstream brand words.

## 5. Network: what the product may contact

Allowed: model and tool providers the operator configures, the operator's own server, models.dev catalog (public model metadata; keep, but honour `CRYBOT_DISABLE_MODEL_CATALOG_FETCH`), npm/pip/GitHub only when a user action needs it.

Remove completely (code and UI entry points): PostHog analytics, upstream cloud accounts and payments, admin/accounts/control-plane clients, upstream bug-report upload and its hourly poll, team library fetch from upstream GitHub, bot directory, sponsor/promo links and widgets, funding manifests, upstream docs/discord/pricing links, `cloudflare/control-plane` and `cloudflare/composio-broker` workers, connector install pointing at upstream images.

Make configurable and default off: announcements feed (`CRYBOT_ANNOUNCEMENTS_URL`, off when unset), model manifest (`CRYBOT_MODEL_MANIFEST_URL`, off when unset), server update check (`CRYBOT_UPDATE_URL`, off when unset), phone relay (`CRYBOT_PHONE_RELAY_URL`, off when unset), managed Composio broker (`CRYBOT_COMPOSIO_BROKER_URL`, off when unset).

Desktop auto-update: electron-builder `publish` uses the generic provider with a URL given at build time (`CRYBOT_UPDATE_FEED_URL`). When it is not set at build time, the updater is disabled. Never GitHub.

The public repo `crysound/crybot` must not contain internal hostnames, IP addresses, e-mail addresses or personal names. Deployment values live in the private repo `crysound/crybot-deploy`.

## 6. Login (Cloudflare Access)

- New `server/cf-access.ts`. Config: `CRYBOT_CF_ACCESS_TEAM_DOMAIN` (e.g. `example.cloudflareaccess.com`), `CRYBOT_CF_ACCESS_AUD` (one or more comma-separated AUD tags), `CRYBOT_CF_ACCESS_ALLOW` (comma-separated e-mails, or `*` to accept every identity that Access admitted).
- Verify `Cf-Access-Jwt-Assertion` with `jose` (`createRemoteJWKSet` on `https://<team>/cdn-cgi/access/certs`, `jwtVerify` with `issuer: https://<team>` and `audience`). Cache keys as jose does.
- When the request has no valid Cry Bot session but has a valid Access JWT and the identity is allowed: issue an owner session cookie the same way `server/routes/email-sign-in.ts` does, then continue the request as that session. Do it in an async step before the main auth gate in `server/index.ts`, so `resolveRequestAuth` stays synchronous and the other call sites (`index.ts` ~12047, `server/routes/threads.ts` ~511) see the cookie.
- When the request carries an Access JWT that is invalid (bad signature, wrong aud/iss, expired), reject with 401 and do not fall through to other trust paths.
- With the env unset, behaviour is unchanged (loopback owner, pairing).
- The server keeps listening on 127.0.0.1 only.
- Static desktop update files: serve `CRYBOT_DESKTOP_UPDATES_DIR` (when set) read-only at `/desktop-updates/` without auth (Access bypasses this path). No directory listing, no path traversal, correct content types for `.yml`, `.zip`, `.dmg`, `.exe`, `.blockmap`, `.apk`.

## 7. Clients

- Web: PWA manifest named `Cry Bot`, new icons.
- Desktop (Electron): product name `Cry Bot`, appId per §2, protocol `crybot`. When built with `CRYBOT_DEFAULT_SERVER_URL`, the first launch connects to that server in remote mode without a pairing step and loads it in the main window. Navigation to the Access team domain and the identity provider pages stays inside the app window (allowlist from build-time `CRYBOT_LOGIN_HOSTS`, comma separated, plus the server host); other links open in the system browser. macOS build: hardened runtime, Developer ID signing and notarization from CI secrets (deploy repo). Windows: NSIS, unsigned.
- Android (`mobile/android`, Kotlin, minSdk 26): one activity with a WebView loading the server URL from a build config field (`CRYBOT_SERVER_URL`, `CRYBOT_LOGIN_HOSTS`). Cookies persist. File upload, downloads, microphone permission for the web page, back button navigates back in history. Hosts outside server + login hosts open in the browser. Icon from `brand/` (adaptive icon: gradient background layer, dome-face foreground layer). Release signing from env (`CRYBOT_ANDROID_KEYSTORE`, `..._PASSWORD`, `..._KEY_ALIAS`, `..._KEY_PASSWORD`).
- iOS (`mobile/ios`, Swift, iOS 16+, XcodeGen `project.yml`): one WKWebView with the default persistent data store, same URL and host rules from build settings, file upload, microphone/camera prompts with Chinese and English usage strings, pull-to-refresh, an offline/error page with retry. Bundle id `com.crysound.crybot`, display name `Cry Bot`, `ITSAppUsesNonExemptEncryption = NO`. App icon 1024 opaque (no transparency) from `brand/`.

## 8. Verification (all tasks)

- `pnpm typecheck` and `pnpm lint` pass; the vitest suites touched by the task pass (`pnpm vitest run <paths> --maxWorkers=2`).
- `pnpm check:locales` or `node scripts/generate-locale.mjs --check` passes after locale changes.
- Residual check script `scripts/check-brand-residue.mjs` (added in T-1207): scans the git tree (excluding `third_party/`, `node_modules/`, `LICENSE`, `NOTICE`, `CHANGES.md`, `LICENSING.md`) for `maus`, `openmaus`, `\bomb[_-]`, `\bOMB_`, `\bomb\b` (case-insensitive where sensible), and exits non-zero on any hit. It also scans built `dist/` and `dist-server/` when they exist. CI runs it.
- The public repo must pass a leak scan for internal hostnames, IPs, e-mails and personal names before it is made public (coordinator runs it).

## 9. Repos

- `crysound/crybot` (to become public): product code, brand, mobile shells, CI for lint/typecheck/tests/residual check only.
